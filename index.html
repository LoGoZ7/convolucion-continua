01 / IDEA CENTRAL

¿Qué hace la convolución?

Permite calcular la salida de un sistema lineal e invariante en el tiempo (LTI) a partir de su entrada y su respuesta al impulso.

01La entrada

Una señal que varía con el tiempo: pulso, escalón, audio o transmisión.

02La memoria del sistema

La respuesta h(t) describe cómo influye cada instante anterior.

03El resultado

La salida suma los aportes ponderados de toda la entrada.

✦ En un sistema LTI con condiciones iniciales nulas: y(t) = x(t) ∗ h(t).

02 / EL MÉTODO

Una integral, cuatro acciones.

La variable τ recorre la señal. El tiempo t indica en qué instante queremos conocer la salida.

y(t) = +∞∫−∞ x(τ) · h(t − τ) dτ
01
↔

Reflejar

Cambiar h(τ) por h(−τ): voltear la respuesta horizontalmente.

02
⇥

Desplazar

Mover la señal reflejada para obtener h(t − τ).

03
×

Multiplicar

Calcular, para cada τ, el producto x(τ)h(t − τ).

04
∫

Integrar

Sumar el área con signo: ese valor es y(t).

OJO No se multiplica x(t) por h(t) punto a punto: primero se refleja y desplaza h, y después se integra respecto de τ.

08 / PROPIEDADES ESENCIALES

Reglas que simplifican problemas.

Estas identidades se cumplen cuando las convoluciones involucradas están bien definidas.

A

Conmutativa

x ∗ h = h ∗ x

Intercambiar el orden de las señales no altera la salida.

B

Asociativa

(x ∗ h₁) ∗ h₂ = x ∗ (h₁ ∗ h₂)

Los sistemas LTI en cascada pueden agruparse.

C

Distributiva

x ∗ (h₁ + h₂) = x ∗ h₁ + x ∗ h₂

La convolución distribuye sobre la suma.

D

Identidad

x ∗ δ = x

La convolución con el impulso unitario ideal conserva la señal.

✦ Para señales causales, la convolución puede escribirse como y(t) = ∫₀ᵗ x(τ)h(t−τ)dτ, para t ≥ 0.
